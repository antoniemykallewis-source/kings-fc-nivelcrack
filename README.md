# Kings FC × Nivelcrack

An interactive sponsor proposal for Conti’s project, created with Vessel Archive.

## Publish with GitHub Pages

1. Create a GitHub repository and upload **all files and folders in this package** to its root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select **main**, and set the folder to **/(root)**.
4. Save and open the Pages URL GitHub provides.

No build command, API keys, or dependencies are required. All assets use relative paths, so repository subpaths work.

## Preview locally

Run this command from the folder containing `index.html`:

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Edit

- `index.html`: copy, partner status, proposed quantities, source notes, and inquiry email.
- `styles.css`: layout, type, colors, and responsive behavior.
- `app.js`: jersey viewer, sponsor name, globe, value tabs, and motion.
- `assets/`: images and local variable fonts.
- `licenses/`: required font license notices.
- `docs/RESEARCH.md`: sources and recent award-winning inspiration.
- `docs/HANDOFF.md`: presentation guidance and items to finalize.
- `docs/preview.jpg`: desktop preview of the finished page.

All sponsor inquiries go to `antonie@vessel-archive.com`, as directed by the project owner. Keep that address on every contact link. No messages are sent automatically.

The site includes reduced-motion support, accessible dialogs, keyboard-operated tabs, responsive layouts, and local assets. There is no backend or analytics collection. The default robots setting is `noindex,nofollow` because this is a proposal.

The floating jersey is a dimensional concept; the interactive viewer uses the original supplied purple artwork. Talent appearances, venue, rights, distribution, and deliverables are proposed where indicated. No budget appears in the pitch.
